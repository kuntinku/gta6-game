**Palma Verde — Sun & Crime**: a top-down open-world crime game. Drive anywhere in a hand-drawn
coastal city, steal cars, run five missions for El Coco, dodge three escalating police wanted
levels, and watch the minimap. Pure HTML5 canvas + vanilla JS, no libraries, no CDN, fully offline.

Controls: WASD move · SHIFT sprint · E enter/exit car · MOUSE aim/shoot · ESC pause.

## Run it

```sh
node serve.ts            # serves game/ on http://localhost:8080
```

Deterministic screenshot scenes: `?shot=1-city|2-chase|3-mission|4-beach&seed=1` (see `screenshots/`).
